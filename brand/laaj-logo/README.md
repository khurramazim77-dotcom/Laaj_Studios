# Laaj Studios logo: arch monogram

An italic L within a double Mughal arch, crowned with a finial dot, over the LAAJ STUDIOS wordmark.
All lettering is converted to outlines, so the SVG files never depend on an installed font.

## Which file to use

| Need | File |
|---|---|
| Website header, letterhead, invoices (light background) | `svg/laaj-logo-horizontal-gold-on-light.svg` |
| Website footer, dark slides, video end cards | `svg/laaj-logo-stacked-gold-on-dark.svg` |
| Album covers, boxes, foil stamping, embossing | `svg/laaj-monogram-gold.svg` (or `-black` for the printer's single-colour plate) |
| Instagram / Facebook / WhatsApp profile photo | `social/instagram-avatar-1080-espresso.png` |
| Watermark on photos and film | `social/watermark-monogram-white.png` or `watermark-horizontal-white.png` at 30–50% opacity |
| Website and phone icons | `favicon/` (uses a simplified heavier arch that stays clear at 16 px) |

Every logo comes in three layouts (`stacked`, `horizontal`, `monogram`) and these colourways:

- `gold-on-dark`: gold mark, ivory LAAJ, gold STUDIOS. For espresso or black backgrounds.
- `gold-on-light`: antique-bronze mark, espresso LAAJ. For ivory or white backgrounds.
- `gold`, `espresso`, `ivory`, `black`, `white`: single colour.

`svg/` is the master artwork: it scales to any size, from a favicon to a banner. `png/` holds transparent high-resolution exports (3000–4000 px wide).

## Type

- LAAJ and the monogram L: Bodoni Moda (regular and italic)
- STUDIOS: Jost Light

Both are free Google Fonts (SIL Open Font License), so they can be used for printing and signage.

## Clear space and minimum size

- Keep empty space around the logo at least the height of the arch's finial dot × 4.
- Smallest size: the stacked logo at 25 mm (100 px) wide. Below that, use the monogram alone.
- Do not stretch, rotate, recolour outside the palette, or add shadows or outlines.
